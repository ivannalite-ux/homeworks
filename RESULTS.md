## 1. Що було зроблено

Під час виконання завдання я створила тест-план у JMeter для API `https://jsonplaceholder.typicode.com`.
У Thread Group налаштувала:

* 1 користувача;
* 3 ітерації;
* Scheduler (обмеження за часом) — 10 секунд.

Для тестування використала 5 HTTP-запитів:

* GET;
* POST;
* PUT;
* PATCH;
* DELETE.

Для кожного запиту додала по 3 assertions, щоб перевірити код відповіді, дані у відповіді та додаткові параметри, наприклад час відгуку або заголовки.

Результати перевіряла через View Results in Tree та Summary Report.

## 2. Результати перевірок

### GET (`/posts/1`)
Перевірила:
* status code — 200;
* наявність `id: 1` у відповіді;
* час відгуку до 2 секунд.

Усі перевірки пройшли успішно.

### POST (`/posts`)
Перевірила:
* status code — 201;
* наявність `id: 101`;
* заголовок `Content-Type: application/json`.

Усі перевірки пройшли успішно.

### PUT (`/posts/1`)
Перевірила:
* status code — 200;
* `"updated title"` у відповіді;
* `userId: 1`.

Усі перевірки пройшли успішно.

### PATCH (`/posts/1`)
Перевірила:
* status code — 200;
* `"patched title"` у відповіді;
* наявність `id`.

Усі перевірки пройшли успішно.

### DELETE (`/posts/1`)
Перевірила:
* status code — 200;
* порожнє тіло відповіді `{}`;
* час відгуку до 2 секунд.

Усі перевірки пройшли успішно.

У View Results in Tree всі 15 запитів (5 запитів × 3 ітерації) пройшли успішно. Усі запити позначені зеленим кольором, помилок не було.
